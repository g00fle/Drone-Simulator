# Operation Lifeline Drone Simulator

Browser-based 3D practice simulator for the 2027 drone challenge course (three.js, no build step).

**Play it:** https://g00fle.github.io/Drone-Simulator/

## Run locally
```
npx serve .
```
Then open the printed URL. (Opening `index.html` directly from disk won't work — ES modules need a web server.)

## Tests
```
node --test
```

## Controls
Keyboard, gamepad, or a USB radio in joystick mode. Press the help button in the simulator for the full key list.
